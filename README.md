# 📒 Contact Book

A Python terminal app to manage your contacts.
Contacts are saved to a file so they stay even after closing!

## Features
- Add new contacts (name, phone, email, category)
- View all contacts in a formatted table
- Search contacts by name, phone or email
- Update existing contacts
- Delete contacts
- View contacts grouped by category (Family, Friend, Work, Other)
- Saves contacts automatically to a JSON file

## How to Run
```bash
python contact_book.py
```
